# Налаштування телефона (MacroDroid)

Два макроси, безкоштовної версії MacroDroid вистачає. Назви пунктів можуть трохи відрізнятися залежно від версії.

Скрізь нижче:
- `URL` — `https://power-health.power-health.workers.dev`
- `KEY` — значення `DEVICE_SECRET` з `.env`

## Підготовка телефона (Xiaomi)

1. **Налаштування → Застосунки → MacroDroid → Батарея → «Без обмежень».**
2. **Застосунок «Безпека» → «Автозапуск»** → увімкнути для MacroDroid.
3. У недавніх застосунках затиснути картку MacroDroid → **🔒 замок**.
4. Мобільний інтернет — увімкнений (коли роутер сяде, телефон піде через мобільні дані).
5. **Телефон — у звичайній розетці**, не через ДБЖ / павербанк / ноутбук, інакше він завжди «на зарядці».

## Глобальна змінна `powerTime`

Змінна — «комірка пам'яті» телефона. Глобальна живе між запусками макросів і доступна всім макросам.

`powerTime` зберігає момент, коли **востаннє змінилась зарядка**. Навіть якщо в цей момент немає інтернету
(подія не дійшла), heartbeat пізніше передасть цей час, і бот напише точне «🟢 Світло з'явилось о 04:30»,
а не час, коли повернувся інтернет.

Створити: **Variables (Змінні) → ＋ → Global, тип String, назва `powerTime`**.

## Макрос 1: «Подія живлення» — миттєві сповіщення

**Тригери:** Battery/Power → **Power Connected** і **Power Disconnected** (будь-яке джерело).

**Дії:**
1. **Set Variable** `powerTime` = `{system_time}` — першою дією, до будь-яких запитів.
2. **If** → умова Battery/Power → Power Connected:
   - **HTTP Request** (розділ **Web Interactions**): `POST URL/device/event`,
     заголовок `X-Device-Key` = `KEY`, тип `application/json`, тіло:
     ```json
     {"charging": true, "ts": "{v=powerTime}", "battery": "{battery}"}
     ```
3. **End If**
4. **If** → умова Power **Disconnected**:
   - такий самий HTTP Request з `"charging": false`
5. **End If**

(`Else` в інтерфейсі може не знайтися — тому два `If`.)

## Макрос 2: «Heartbeat» — стан щохвилини

**Тригери:**
- Date/Time → **Regular Interval** 1 хв

Чому щохвилини: роутер на ДБЖ, тож Wi-Fi лишається підключеним, а пропадає інтернет у провайдера. Коли він повертається,
тригери «Wi-Fi підключено» / «Data Available» не спрацьовують (для телефона нічого не змінилось). Хвилинний heartbeat
доставляє зміну щонайпізніше за хвилину після появи інтернету, а точний час бере з `changed_at`. Це ~1 440 запитів на
добу — ~2% безкоштовного ліміту Cloudflare; на зарядці Android інтервали не «присипляє».
- Device Events → **Device Boot**

**Дії** — ті самі два `If`, але `POST URL/device/heartbeat` і тіло:
```json
{"charging": true, "ts": "{system_time}", "changed_at": "{v=powerTime}", "battery": "{battery}"}
```
(у гілці «відключено» — `"charging": false`).

`ts` — момент відправки, `changed_at` — коли востаннє змінилась зарядка. Сервер використовує `changed_at` лише тоді,
коли стан змінився, а подія не дійшла; інакше ігнорує. Якщо змінна ще порожня — теж ігнорує.

Глобальну змінну в Magic Text позначають `{v=назва}` (локальну — `{lv=назва}`); надійніше вставити через кнопку Magic Text.

## Перевірка

1. **Heartbeat → Test Actions** — у `/status` має оновитися «на зв'язку … тому».
2. Відключи зарядку на 6+ хв (коротші відключення бот стирає як «блимання») — у каналі «🔴 Світло зникло о …»;
   підключи — «🟢 Світло з'явилось о …».
3. Без інтернету: режим польоту → відключи зарядку на 6+ хв → підключи → вимкни режим польоту. Після появи мережі
   бот має написати про зникнення і появу світла з **точним** часом підключення зарядки.
